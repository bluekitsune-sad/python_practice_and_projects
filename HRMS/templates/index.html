Quick start

  1. Employees - add people (ID like emp_001 is automatic). Mark leavers as ex to keep their history, or delete them.
  2. Attendance - pick employee + date (defaults to today), enter arrival time and hours. Arriving after the late time is marked Late; you can also mark Approved leave or Absent.
  3. Export - choose month + year, download CSV or XLSX. Days you never marked are filled as Absent here (off days like Saturday are skipped). Upload it to Google Drive / Sheets as-is.
  4. Import JSON - load a correctly formatted JSON file to bulk-update employees / attendance.

Notes

No login - the app only runs on this computer while it is open. All data lives in the data/ folder as JSON files, so back those up.
