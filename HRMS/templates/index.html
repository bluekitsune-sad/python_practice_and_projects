Quick start

  1. Employees - add people (ID like emp_001 is automatic). Mark leavers as ex to keep their history, or delete them.
  2. Attendance - pick employee + date (defaults to today) + day type (Worked / Approved leave / Absent). Arriving after the late time is marked Late.
  3. Transactions - save an image/receipt with name, date, amount and optional client. Search a month (total + how many people) or one person's complete history.
  4. Calendar - month grid: each day shows its transaction total and attendance %, with the month's attendance % and total beside the month name.
  5. Totals - graphs and totals of everything: monthly bars, top people donut, this-month KPIs.
  6. Export - choose month + year, download the attendance CSV/XLSX (unmarked working days are auto-filled as Absent). Upload it to Google Drive / Sheets as-is.
  7. Import JSON - load a correctly formatted JSON file to bulk-update employees / attendance.

Notes

No login - the app only runs on this computer while it is open. All data lives in the data/ folder as JSON files (transaction images in data/uploads/), so back those up.
