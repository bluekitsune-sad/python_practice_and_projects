Import a JSON file

Uploading a correctly formatted JSON file updates the web data: existing records are updated, new ones are added. Nothing is deleted.

Expected format

Both keys are optional - include just the part you want to update. Every field except name can be omitted. 

{
  "employees": [
    { "id": "emp_001", "name": "Ali Khan", "department": "Operations",
      "designation": "Supervisor", "active": true }
  ],
  "attendance": {
    "emp_001": {
      "2026-10-01": { "arrival": "09:00", "hours": 8, "status": "Present" },
      "2026-10-02": { "arrival": "22:30", "hours": 8, "status": "Late" },
      "2026-10-03": { "arrival": "",      "hours": 0, "status": "Absent" },
      "2026-10-06": { "arrival": "",      "hours": 0, "status": "Leave" }
    }
  }
}

Notes: an employee without an id gets the next free one. A missing/unknown status is recomputed from arrival vs the late time. status must be Present, Late, Absent or Leave (approved leave).
